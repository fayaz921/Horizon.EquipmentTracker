- (constraint) Fixed stack: .NET 9 ASP.NET Core Web API, EF Core 9, SQL Server LocalDB, React (Vite) + TypeScript + Bootstrap 5.3.
- (constraint) Repository layout: single monorepo with exactly two projects: src/Horizon.EquipmentTracker.Api and src/client. No extra projects, class libraries, background services, queues, or distributed caching.
- (decision) AD-1 [ADOPTED]: Single-Project Modular API Boundary. src/Horizon.EquipmentTracker.Api directly contains Data, Controllers, Models, and Common; prevents multi-project overhead and complex abstraction drift for 1-week build.
- (decision) AD-2 [ADOPTED]: Timezone and Business Date Canonical Representation. Store all database audit timestamps in UTC; represent ExpectedReturnDate as DateOnly (ISO yyyy-MM-dd); evaluate all business calendar days and overdue status strictly against Pakistan Standard Time (PKT, UTC+05:00).
- (decision) AD-3 [ADOPTED]: Equipment Inventory Duality & Concurrency Protection. Separate serialized equipment (individual state machine) from counted equipment (quantity pools); enforce EF Core optimistic concurrency / rowversion token on counted pools to prevent overselling on concurrent checkout.
- (decision) AD-4 [ADOPTED]: Trust-First Passwordless Field Attribution. Day-to-day checkouts and returns require no auth credentials or session cookies; every checkout line records RecipientId and LoggedById to guarantee attribution without morning login hurdles.
- (decision) AD-5 [ADOPTED]: Queue-Only Restricted Approval with Operator PIN Gate. Restricted items (the drone) transition strictly into Pending Approval; released to Out only upon submission of designated approver PIN hash; strictly no inline checkout PIN and strictly no Admin override.
- (decision) AD-6 [ADOPTED]: Admin PIN Header Authorization Boundary. Privileged actions (clearing inspection, setting Lost, modifying catalog, toggling approval requirements) require the HTTP X-Admin-PIN header validated against SHA-256 hash in appsettings.json.
- (decision) AD-7 [ADOPTED]: Return Condition Verification and Instant Damage Quarantine. Returns mandate Condition parameter (Good | Damaged); Damaged immediately transitions serialized items to NeedsInspection and increments CountedInventory.QuantityInInspection, isolating broken gear from morning dispatch.
- (decision) AD-8 [ADOPTED]: Overdue Boundary & Extension Gate. Overdue status begins at 00:00 PKT on the day following ExpectedReturnDate; surveyors can self-extend active checkouts before delinquency; overdue checkouts require Admin PIN; every extension records immutable DueDateExtensionLog.
- (decision) AD-9 [ADOPTED]: Client-Side WhatsApp Link Formatting. WhatsApp nudges are rendered directly on the client using standard https://wa.me/{phone}?text={encoded} links with automatic Pakistani local phone (0300...) normalization to international E.164 (92300...); zero server-side messaging dependencies.
- (decision) AD-10 [ADOPTED]: Startup Migration and Demo Seeder. Application startup in Program.cs automatically invokes Database.Migrate() and executes DatabaseSeeder if Personnel table is empty; seeds demo users, serialized gear, counted pools, kits, and sample overdue/historical checkouts.
- (question) Q1: API Endpoints Organization: Should the backend use ASP.NET Core Controller classes ([ApiController]) or .NET 9 Minimal API Route Groups?
- (question) Q2: Client State Management: Should the React SPA use simple fetch + useState/useEffect custom hooks (zero external deps) or TanStack Query (React Query) for API synchronization?
- (question) Q3: Counted Inventory Concurrency: Should concurrent checkout overselling protection be enforced via EF Core RowVersion concurrency token (optimistic lock with 409 Conflict) or direct DbContext transaction with in-flight quantity validation?
- (decision) Q1 resolved: [ApiController]-decorated controller classes (one per domain). Minimal API route groups not used. AD-1 updated.
- (decision) Q2 resolved: Custom React hooks with typed native browser fetch; zero external state libraries. Client State Management convention added to spine.
- (decision) Q3 resolved: EF Core RowVersion optimistic concurrency on CountedInventory, SerializedEquipment, and CheckoutLine; DbUpdateConcurrencyException -> HTTP 409 Conflict ProblemDetails; UI surfaces detail in active modal. AD-3 expanded.
- (event) spine finalized
